# Personalized Reading Report Template

## One-sentence Takeaway

State what the book is really useful for, and what it is not useful for.

## Book Structure

List parts, chapters, and page ranges. Mention if the table of contents was reconstructed from OCR.

## What The Book Says

Summarize the book objectively before personalizing. Include:

- Core thesis
- Repeated concepts
- Author's operating assumptions
- Most actionable ideas
- Most controversial ideas

## User Context Used

Separate known facts from assumptions.

- Known from conversation:
- User-provided personal context:
- Assumptions:
- Missing context:

## What Applies To The User

Translate book ideas into user-specific implications. Avoid generic advice. Tie each recommendation to a known user fact or stated goal.

## What Does Not Apply Or Needs Caution

List ideas that are risky, overgeneralized, outdated, too context-dependent, or unsupported for the user's situation.

## Action Plan

Offer a 7-day, 30-day, or 90-day plan. Prefer observable actions and outputs.

## Questions For A Deeper Version

Ask only the minimum remaining questions needed to improve personalization.
